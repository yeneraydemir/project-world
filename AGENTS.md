# Project World çalışma kuralları
- Ana kaynak ve kalıcı sürüm geçmişi özel GitHub deposudur: yeneraydemir/project-world.
- Değişiklikleri tamamlamadan önce GitHub'a yaz ve uzak commit/dosyaları doğrula.
- Sites yayını tek başına yedek değildir. Çalışma alanı geçicidir.
- Kontroller: npm ci, npm run build, npm run check, npm test.
- Kullanıcı saha verileri kaynak kodundan ayrıdır. Gerçek kişi/veri, anahtar veya tarayıcı yedeğini depoya ekleme.
- 3D görünüm doğrulanamadıysa test edilmiş gibi anlatma.
- Veri şeması değişikliklerini sürümle; mevcut kullanıcı kaydını sessizce silme.
- docs/KAPSAM.md ürün kararlarının kaydıdır; uygulanmış özelliklerle planlananları ayırt et.
